# 👾 Hackerské nástroje pre deti

Zábavná a **bezpečná** webová stránka, vďaka ktorej sa deti cítia ako ozajstní hackeri –
a pritom sa učia o programovaní, šifrách a bezpečnosti na internete. 🟢

> 🛡️ **Dôležité:** Nič tu nie je ozajstné hackovanie. Všetko je vzdelávacie a pre zábavu.
> Učíme deti, že pravý hacker je **zvedavý a pomáha** – nikdy neubližuje.

## ✨ Čo stránka obsahuje

| Nástroj | Čo robí | Čo sa dieťa naučí |
|---|---|---|
| 💻 **Terminál** | Píš príkazy (`help`, `hack`, `joke`...) ako hacker | Ako funguje príkazový riadok |
| 🔐 **Tajná šifra** | Caesarova šifra – posun písmen v abecede | Základy kryptografie |
| 🤖 **Binárny kód** | Preloží text na jednotky a nuly a späť | Ako počítače ukladajú text |
| 📡 **Morseovka** | Preklad textu na bodky/čiarky + zvuk | Historický spôsob komunikácie |
| 🔑 **Generátor hesiel** | Vytvorí silné náhodné heslo | Prečo sú silné heslá dôležité |
| 🧠 **Kvíz** | Otázky o bezpečnosti na internete | Bezpečné správanie online |

Plus efektný **Matrix dážď** v pozadí a glitch animácie. 🟩

## 🚀 Ako spustiť

Žiadna inštalácia nie je potrebná – je to čistý HTML/CSS/JavaScript.

**Možnosť 1 – jednoducho:** Otvor súbor `index.html` v prehliadači (dvojklik).

**Možnosť 2 – lokálny server** (odporúčané, kvôli zvuku Morseovky):

```bash
# Python 3
python3 -m http.server 8000
# potom otvor http://localhost:8000
```

## 🧒 Pre rodičov a učiteľov

Tento projekt nepoužíva žiadne externé knižnice, nesleduje deti, neukladá dáta
a nepripája sa nikam na internet. Je úplne offline a bezpečný. Skvelý spôsob,
ako u detí vzbudiť záujem o informatiku a kybernetickú bezpečnosť.
